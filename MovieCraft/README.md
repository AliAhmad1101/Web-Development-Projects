# MovieCraft
Find your next favorite movie in seconds.

MovieCraft is a movie recommendation website built to eliminate endless scrolling. With a curated database of 1000+ movies, it helps users quickly discover films that match their mood, genre preference, and viewing style. Whether you're looking for something intense, feel-good, underrated, or mind-bending. MovieCraft helps you find it instantly.

## What Makes It Different?
Unlike traditional browsing platforms, MovieCraft offers:

Smart filtering for fast discovery

Mood-based movie suggestions

Advanced genre exploration

Instant search results

Clean, distraction-free UI

No clutter. No decision fatigue. Just good movies.

## Features
